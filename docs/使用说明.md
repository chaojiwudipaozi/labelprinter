# 标签打印工具站 · 使用说明（部署 / 运维版）

一款企业标签打印工具：Excel 导数据 → 设计标签 → 直连打印机批量出纸。
既有**桌面安装版**（推荐给一线用户），也有**网页版**（适合集中部署在服务器）。

> **两份文档的分工**
> - **《使用手册.md》**（同目录）：面向**安装 EXE 的普通用户**——安装、界面、设计标签、Excel 数据、打印、模板、FAQ，全程无需命令行。
>   该手册已**内置到安装包**：软件内点右上角「❓ 使用手册」或按 `F1` 即可离线查看。
> - **《使用说明.md》**（本文件）：面向**安装部署与维护人员**——启动命令、端口、局域网放行、打包、目录结构、故障排查。

| 项目 | 说明 |
| --- | --- |
| 程序目录 | `D:\label-print` |
| 默认端口 | **11235**（可配置） |
| 本机访问 | `http://localhost:11235` |
| 局域网访问 | `http://本机IP:11235`（当前示例：`http://192.168.1.23:11235`） |
| 模板存放 | `label-print\data\labels\*.json` |
| 运行环境 | Windows 10/11 + Node.js 16 以上（已验证 v23.11.1） |

## 零、桌面版（推荐给普通用户）

不想敲命令？直接用安装包：**`label-print\dist\LabelPrint-Setup-1.2.1.exe`**（当前版本 **V1.2.1**，界面左上角有版本徽标可核对）

1. 双击安装（可自选安装目录，会创建桌面与开始菜单快捷方式）；
2. 打开「标签打印工具站」→ 程序会**自动启动内置服务并打开界面**；
3. **安装到哪台电脑，就自动识别并使用哪台电脑的打印机**（打印机识别、状态监测、静默打印全部在本机执行）；
4. 标签模板保存在 `C:\Users\<用户名>\AppData\Roaming\label-print-site\data\labels`（卸载重装不丢）；
5. 菜单「文件 → 打开数据目录」可直接打开模板目录；「文件 → 显示访问地址」可查看本机与局域网访问地址（供其他电脑用浏览器访问）。

> 桌面版与网页版是同一套程序：桌面版更适合"每台电脑各装一份、各自用自己的打印机"；网页版适合集中部署一台服务器。
> 重新打包：`npm run dist`（生成安装包）或 `npm run pack`（只生成免安装目录 `dist\win-unpacked`）。
> 安装后随包附带文档：`<安装目录>\resources\docs\使用手册.md`、`使用说明.md`；软件内「帮助 → 使用手册（F1）」可直接阅读。
> 文档更新后执行 `npm run sync-manual` 同步到应用内（`npm run dist` 会自动先同步）。

## 一、网页版启动命令

### 1. 首次启动（安装依赖 + 启动）

在 `cmd` 或 PowerShell 中执行：

```bat
cd /d "D:\label-print"
npm install
npm start
```

看到下面输出即表示启动成功：

```
标签打印工具站已启动: 监听 0.0.0.0:11235
  本机访问:     http://localhost:11235
  局域网访问（其他主机请用这些地址）:
    http://192.168.1.23:11235    [WLAN]
标签模板存储目录: ...\label-print\data\labels
```

### 2. 日常启动

```bat
cd /d "D:\label-print"
npm start
```

等价写法（不需要 npm）：

```bat
cd /d "D:\label-print"
node server.js
```

### 3. 换端口 / 只允许本机访问

```bat
node server.js --port=9000            :: 换端口
node server.js --host=127.0.0.1       :: 只监听本机（局域网不可访问）
set PORT=9000 && node server.js       :: 用环境变量指定端口
```

### 4. 后台启动与停止

```bat
:: 后台（隐藏窗口）启动
powershell -NoProfile -Command "Start-Process -WindowStyle Hidden node -ArgumentList 'server.js' -WorkingDirectory 'D:\label-print'"

:: 查看端口占用（末列是进程号 PID）
netstat -ano | findstr :11235

:: 停止服务
taskkill /PID <上面的PID> /F
```

### 5. 局域网放行（首次必做，需管理员）

Windows 防火墙默认拦截入站连接，**其他电脑要访问必须先放行一次**：

```bat
:: 在【以管理员身份运行】的终端里执行
cd /d "D:\label-print"
npm run lan
```

等价的完整命令（可指定端口）：

```bat
powershell -ExecutionPolicy Bypass -File scripts\fix-lan-firewall.ps1 -UnblockNode -Port 11235
```

脚本会：① 放行入站 TCP 11235（默认仅限本地子网）；② 禁用 `node.exe` 的入站「阻止」规则；
③ 打印可用的访问地址。执行过一次即可，之后不需要重复。

> 撤销放行：`powershell -File scripts\fix-lan-firewall.ps1 -Remove`

### 6. 可选：做一个双击启动的快捷方式

在 `D:\label-print` 下新建 `启动.bat`，内容：

```bat
@echo off
cd /d "%~dp0"
start "" http://localhost:11235
node server.js
pause
```

以后双击即可启动并自动打开浏览器。

## 三、三分钟上手

标准流程：**下载模板 → 填数据 → 导入 → 设计标签 → 设置份数 → 打印**

1. **下载模板**：底部数据区点「下载Excel模板」，得到 `标签打印数据模板.xlsx`（含 2 行示例数据与「填写说明」工作表）。
2. **填写数据**：一行数据 = 一张标签，不要改第 1 行列名。填完保存为 `.xlsx`。
3. **导入数据**：点「导入Excel」选择文件，底部表格会列出所有行，并给出校验报告（缺少/附加/自动生成的列、合计份数）。
4. **设计标签**：顶部功能区「插入」页签里选 文本/条形码/二维码/矩形/直线；也可以**在画布空白处按住拖拽，直接“画”出一个文本区域**。
   - **双击**任意元素 → 弹出快捷编辑器：改文字、点字段名即**绑定 Excel 列**、调字体字号。
   - 拖动移动，拖四角/四边手柄缩放；方向键微调 1mm。
5. **设置打印份数**：底部表格最后一列「打印数量」，逐行填写（`0` 表示该行不打印）；也可用「统一份数 + 应用」批量设置。
6. **选打印机并打印**：顶部右侧选择目标打印机（显示 空闲/打印中/脱机/已暂停/异常 与队列长度），然后点「批量打印（按行份数）」。

> 保存标签：【开始】页签 →「保存模板」。模板会出现在**左侧列表**，点击即可重新载入；卡片右上角可删除；模板会同时记住所用打印机。

### 界面结构

| 区域 | 作用 |
| --- | --- |
| 顶部功能区 | 页签「开始 / 插入 / 打印」，左侧是标签模板列表；顶部右侧是标签状态、服务端状态与打印机选择 |
| 左 侧 | 已保存的标签模板列表（单击载入、右上角删除、顶部新建/刷新） |
| 中 间 | 标签画布（所见即所得，支持拖拽设计与双击编辑） |
| 右 侧 | 属性面板（位置尺寸、绑定列下拉、字体字号、码制等精确设置） |
| 底 部 | Excel 数据区（下载模板、导入、校验报告、逐行数据与打印数量） |

## 四、功能清单

### 设计
- 元素类型：文本、条形码（CODE128/CODE39/EAN13/EAN8/UPC/ITF14/ITF/MSI/pharmacode/codabar）、二维码（纠错等级 L/M/Q/H）、矩形框、直线、**表格**。
- **插入当前日期时间**（插入页签）：一键生成文本框，内容自动取当前日期时间，默认格式 `YYYY/M/DD HH:MM`（**月份不补零**，如 `2026/9/21 09:05`），可切换 8 种格式（含 `YYYY-MM-DD HH:MM`、`YYYY年M月D日 HH:MM`、带秒等）；预览/打印时取当时时间。
- **插入表格**（插入页签 →「表格…」）：可预选行数(1~30)×列数(1~20)、表格宽高与线宽，带网格预览与常用规格快捷键；插入后：
  - **双击表格进入编辑模式**（浮动工具条出现）；**编辑模式会一直保持**——点选其他元素或点击空白处都不会退出，随时可回来继续操作；退出请按 `Esc`、浮动条「✓ 完成」或属性面板「✓ 完成表格编辑」；未在编辑状态时，属性面板有「✎ 编辑表格」按钮可随时重新进入；
  - **拖拽框选**多个单元格 → 点「合并单元格」，**合并后内容默认上下左右居中**；可「拆分」还原；
  - 拖动**蓝色分隔线**自由调整行高/列宽（与相邻行列此消彼长，总尺寸不变；末行/末列直接改变表格尺寸）；
  - 支持 ＋行/＋列/－行/－列；双击单元格可编辑内容、绑定 Excel 字段、调字体字号与水平/垂直对齐；Esc 或「✓ 完成」退出。
- 文本：前缀 + 绑定字段组合（如「物料编码：」+ 表格里的物料编码列）、9 种字体、4~72pt、加粗、左中右对齐。
- 布局：拖动、八向缩放手柄、方向键微调、上移/下移图层、复制、删除。
- **标签纸尺寸**：功能区「标签纸」按钮 → 27 个标准尺寸（常用条码标签 / 仓储物流面单 / 线缆资产 / A4 等办公纸）+ 自定义尺寸，支持 **毫米 mm（默认）/ 厘米 / 英寸** 三种单位、纵向横向互换、实时预览（含英寸换算与长宽比）。

### 数据
- 标准 Excel 模板：17 列标准字段（物料编码、物料名称、规格、型号、数量、单位、批号、序列号、供应商编码、供应商名称、生产日期、有效期至、采购单号、任务单号、二维码内容、条码内容、打印数量）。
- **多工作表导入**：工作簿含多个工作表时默认全部识别并合并（主表提供列名，其余表按列名对齐合并、独有列自动追加；无数据行或与主表无同名列的表会跳过并在面板说明原因），也可在「导入结果」面板取消勾选后单独指定工作表与表头行。
- 导入时自动：表头去空格、忽略整行空行、二维码/条码内容留空则按「物料编码;批号;生产日期」自动生成、给出校验报告。
- 支持 `xlsx / xls / csv`；可在标准列右侧自行追加列，同样能绑定到标签。

### 设计
- **上一步 / 下一步**：设计改动可撤销/重做（`Ctrl+Z` / `Ctrl+Y`，最多 60 步；连续拖动自动合并为一步）。
- **自适应字号**：文本框、条形码文字、表格单元格均默认开启——内容始终一行，超出宽度自动缩小字号（最小 3pt），可在属性面板或双击的快捷编辑器里关闭（关闭后按原字号换行）。
- **对齐统一**：单元格与文本框的水平/垂直对齐在屏幕、浏览器打印预览、直连打印三处完全一致。

### 打印
- **打印机识别**：自动列出打印服务所在电脑的全部打印机（惠普、斑马、佳能、爱普生、TSC、Godex 等 20+ 品牌，斑马可识别 GX/GK/ZD/ZT/ZQ/QL/ZP/105SL/110Xi 等系列），显示状态（空闲/打印中/脱机/已暂停/异常）与打印队列长度，每 10 秒自动刷新；「详情」可查看驱动、端口并选为打印目标。
- **打印服务切换（打印到局域网其他设备的打印机）**：浏览器出于安全限制**无法读取打开网页这台电脑的打印机**，所以采用「打印服务（代理）」方式——**哪台设备要打印，就在那台设备上运行本程序**（`node server.js`），然后在网页顶部「打印服务」里填入该设备地址（如 `http://192.168.1.33:11235`），即可列出并使用**那台设备上的打印机**。选项为空时表示用当前打开页面的服务端。
- **打印机诊断**：详情弹窗内点「诊断」→ 检查已安装驱动、未使用的 TCP/IP 端口、已连接但未安装的硬件，并给出针对本机生成的添加打印机命令（专治"某台打印机看不到"）。
- **直接打印（推荐）**：不用选任何对话框，标签会以约 305dpi 渲染后直接送入所选打印机的队列，按每行的「打印数量」连续出纸。
- **浏览器预览打印（备用）**：需要自行预览或改打印机设置时使用，会弹出浏览器打印对话框。

## 五、常见问题

**Q1：局域网其他电脑打不开页面？**
依次检查：
1. 对方用的是 `http://本机IP:11235`（不是 localhost）；
2. 是否执行过「局域网放行」（管理员运行 `npm run lan`）——这是最常见原因；
3. 若曾点过防火墙弹窗的「取消」，会残留 `node.exe` 的**入站阻止**规则（阻止优先于允许，且按程序拦截、**与端口无关**），必须用 `-UnblockNode` 参数禁用；
4. 两台电脑是否在同一网段（对比 IP 与子网掩码）；
5. 让对方执行 `ping 本机IP` 与 `telnet 本机IP 11235`：能 ping 通但 telnet 不通多半是防火墙，两者都不通则是网络/路由问题。

**Q1-3：网页右上角的「⬇ 下载安装包」按钮是灰的 / 点了没下载？**
该按钮下载的是**服务器上放的安装包文件**（`LabelPrint-Setup-*.exe`），需要你放一份：

| 场景 | 放哪 |
|---|---|
| 桌面安装版 | `<数据目录>\installer\`（数据目录见版本徽标悬停提示，通常为 `%APPDATA%\label-print-site\data`） |
| 源码 / 免安装版 | 程序目录旁：`<程序目录>\dist\`、`<程序目录>\installer\`，或程序目录/上级目录里任意位置 |
| 自定义 | 设环境变量 `LABEL_INSTALLER_DIR=D:\安装包` 后重启服务 |

查当前状态（`available` / `version` / `searched` 会列出实际搜索过的目录）：

```bat
curl http://localhost:11235/api/installer
```

要点：① 只识别 `LabelPrint-Setup-<版本>.exe`（其它文件名/半截文件会被忽略）；② 多个版本自动取**版本号最高**者；
③ 放好后刷新页面即可，局域网其他电脑打开同一网址也能下载；④ 安装在 `C:\Program Files` 的版本里没有 dist 目录，请用 `<数据目录>\installer`。

**Q1-2：界面版本号比安装包低（例如安装包 V1.2.1 却显示 V1.0.4），或"检查更新"提示网页层版本较低？**
这是**过期热更新**（`<数据目录>\web` 里的网页文件比安装包旧，把它挡住了）造成的。V1.1.2 起已从根上修复：

| 规则 | 说明 |
|---|---|
| 生效条件 | 覆盖层**版本号 ≥ 安装包版本**时才生效（热更新只用于"补丁超前"） |
| 自动清理 | 启动时检测到过期覆盖层立即删除（这些只是网页缓存文件，删掉不影响标签模板与数据），控制台会打印 `[更新] 已清理过期热更新：V1.0.4` |
| 拒绝降级 | `POST /api/update/apply` 收到低于安装包版本的更新包直接返回 400（`downgrade: true`） |
| 版本口径 | `/api/version` 同时返回 `version`（安装包）与 `webVersion`（生效网页层，= max(安装包, 生效覆盖层)）；`/api/update/manifest` 的 `version` 也是生效网页层版本 |

手工排查（服务端在跑时可随时执行）：

```bat
:: 看两个版本是否一致（staleOverride/stalePurged 会明确告知）
curl http://localhost:11235/api/version

:: 直接清掉覆盖目录，回到安装包自带版本（也可用界面「版本日志 → 清除过期文件 / 回滚到安装版本」）
curl -X POST http://localhost:11235/api/update/rollback
```

**Q1-1：某台打印机（如 Zebra GX430）在工具里看不到？**
先打开顶部打印机「详情」→ 点 **「诊断：为什么找不到我的打印机？」**，会给出本机驱动、端口与设备的检查结论。常见原因与处理：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 打印机列表里没有该型号 | **Windows 里根本没有安装它**（只是插着 USB / 接了网线） | 先装厂商驱动（斑马装 **ZDesigner** 驱动），再添加打印机 |
| 诊断显示「已创建但没有任何打印机使用的 TCP/IP 端口」（如 `192.168.1.27`） | 之前删除过队列，或只建了端口没建打印机 | 用下面的命令把打印机加回来 |
| 诊断显示「已安装斑马驱动但没有对应的打印机」 | 驱动已就绪，只差添加打印机 | 同上 |
| 诊断显示「已连接但未安装为打印机的设备」 | 硬件被识别但缺驱动/队列 | 安装厂商驱动后添加打印机 |
| 打印机在 Windows 里能看到，工具里却没有 | 浏览器缓存或服务未刷新 | 点「↻ 立即刷新」，或重启服务后刷新页面 |

添加打印机的命令（**先用 `-ListDrivers` 查本机可用驱动名**，再以**管理员身份**执行）：

```bat
cd /d "D:\label-print"

:: 1) 查看本机已安装的打印驱动（斑马多为 ZDesigner <型号> (ZPL)）
powershell -ExecutionPolicy Bypass -File scripts\add-printer.ps1 -ListDrivers -Filter Zebra

:: 2) 添加网络打印机（自动创建 TCP/IP 端口，默认 RAW:9100）
powershell -ExecutionPolicy Bypass -File scripts\add-printer.ps1 ^
  -Name "Zebra GX430t" -Ip 192.168.1.27 -Driver "ZDesigner GX430t (ZPL)"

:: 3) 添加 USB 打印机（端口名可先用 -ListPorts 查，如 USB010）
powershell -ExecutionPolicy Bypass -File scripts\add-printer.ps1 ^
  -Name "Zebra GX430t" -Port USB010 -Driver "ZDesigner GX430t (ZPL)"

:: 4) 删除（如需）
powershell -ExecutionPolicy Bypass -File scripts\add-printer.ps1 -Name "Zebra GX430t" -Remove
```

> 本工具**只列出 Windows 已安装的打印机**，不会凭空发现网线上的设备；这也是为了确保打印走的是系统打印队列（稳定、可查队列状态）。
> 若驱动列表里没有 GX430，请先到斑马官网下载对应型号的 ZDesigner 驱动安装，再执行第 2 步。

**Q1-2：能不能直接检测「打开网页这台电脑」的打印机？**
不能——浏览器安全沙箱不允许网页枚举本机打印机（没有任何相关 API）。本工具采用**打印服务**方案：

1. 在要打印的那台电脑上安装本程序并启动（`node server.js`，可用 `--port` 指定端口）；
2. 打开它的防火墙入站端口（管理员执行 `npm run lan`）；
3. 在网页顶部「打印服务 → ＋」填入该电脑地址，如 `http://192.168.1.33:11235`；
4. 之后打印机列表、状态监测、直连打印都会作用在**那台电脑的打印机**上。

> 提示：也可以只用一种简单方式——把本程序部署到需要打印的每台电脑上，各自打开 `http://localhost:11235` 使用自己的打印机。

**Q2：点「批量打印」没反应/打印机不动？**
1. 看顶部打印机状态：**脱机**通常是设备未开机、USB 未插好，或 Windows 里勾选了「脱机使用打印机」；
2. 「异常」会提示卡纸/缺纸/碳粉不足等具体原因；
3. 目标打印机是否选对（顶部下拉或「详情」里选为打印目标）；
4. 部分打印机需要在驱动里把纸张设为对应标签规格，尺寸与实装纸不一致时可能缩放或走纸异常。

**Q3：为什么点「浏览器预览打印」会弹对话框，而「批量打印」不会？**
浏览器出于安全策略，`window.print()` **必然**弹出系统打印对话框，网页无法绕过。「批量打印」走的是服务端直连打印，所以没有对话框。

**Q4：启动时提示端口被占用？**
```bat
netstat -ano | findstr :11235     :: 查到 PID
taskkill /PID <PID> /F            :: 结束占用进程
:: 或换个端口
node server.js --port=9000
```

**Q5：模板保存在哪？怎么备份/迁移？**
全部在 `label-print\data\labels\*.json`（一个模板一个文件）。复制该目录到新机器同位置即可完成迁移。
Excel 数据不会落盘，只保存在浏览器缓存（localStorage）里，刷新页面仍在，换浏览器或清缓存会丢失，重要数据请保留原 Excel。

**Q6：打印产生的临时文件在哪？**
`label-print\data\print-tmp\`，每个打印任务用完即删，残留超过 1 小时也会自动清理，可放心。

**Q7：关闭命令行窗口后服务就断了？**
`npm start` 是前台运行，关掉窗口服务即停止。需要常驻请用「后台启动」（见第 4 节）或做成 Windows 计划任务/服务。

**Q8：换电脑后打印机不见了？**
打印机识别依赖运行服务端的这台电脑。服务端在哪台机器，就识别哪台的打印机；网上邻居共享的打印机也能识别（显示为 IP/WSD 端口的打印机）。

## 六、目录结构

```
label-print/
├─ server.js                服务端入口（可独立运行，也可被桌面版内嵌启动）
├─ package.json             依赖与 npm 脚本（start / electron / pack / dist / lan / verify）
├─ electron/
│  └─ main.js               桌面版主进程（内嵌服务 + 窗口 + 菜单 + 自检）
├─ lib/
│  ├─ paths.js              路径工具（打包/开发两套目录规则）
│  ├─ printers.js           打印机识别与状态归一化
│  ├─ printer-diag.js       打印机诊断（驱动/端口/设备）
│  ├─ silent-print.js       服务端静默打印（图片 → 打印机队列）
│  └─ updater.js            网页层增量更新（清单/差异/应用/回滚/过期清理）
├─ public/                  网页前端（由内置服务托管）
│  ├─ index.html
│  ├─ css/style.css
│  ├─ js/app.js
│  ├─ lib/                  前端依赖（xlsx / JsBarcode / qrcode）
│  └─ docs/                 应用内文档（由 npm run sync-manual 从 docs/ 同步生成）
├─ scripts/
│  ├─ sync-manual.js        同步 docs/ 文档到 public/docs/
│  ├─ verify.js             本地自检（语法检查 + 启动服务探活）
│  ├─ list-printers.ps1     读取本机打印机状态
│  ├─ print-images.ps1      静默打印标签位图（不弹对话框）
│  ├─ printer-diag.ps1      打印机诊断（驱动/端口/设备，排查"看不到打印机"）
│  ├─ add-printer.ps1       添加 USB/网络打印机（需管理员）
│  └─ fix-lan-firewall.ps1  局域网防火墙放行（需管理员）
├─ build/icon.ico           应用图标
├─ docs/                    项目文档（使用手册 / 部署说明 / 截图）
├─ .github/                 Issue 模板、PR 模板、CI
└─ data/                    运行期数据（自动生成，不纳入版本控制）
   ├─ labels/               标签模板（重要，注意备份）
   ├─ installer/            放 LabelPrint-Setup-*.exe → 网页右上角「⬇ 下载安装包」即可分发
   ├─ web/                  热更新覆盖目录（增量更新写入；**版本低于安装包时启动会自动清理**）
   └─ print-tmp/            打印临时文件（自动清理）
```

> 打包产物输出到 `dist/`（`npm run pack` 生成免安装目录、`npm run dist` 生成安装包），同样不纳入版本控制。
