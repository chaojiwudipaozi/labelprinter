其他主机无法访问时请依次检查：
  1. 对方输入的地址必须是上面的局域网地址，不能用 localhost（localhost 永远指向对方自己）。
  2. Windows 防火墙：默认拦截入站连接。请以管理员身份运行 scripts\fix-lan-firewall.ps1 -UnblockNode 放行入站 TCP 11235。
  3. 若存在 node.exe 的入站「阻止」规则（Windows 中阻止优先于允许，且按程序拦截、与端口无关）， 必须加参数：-UnblockNode，否则换任何端口都无效。
  4. 确认两台主机在同一网段（对比双方 IP 与子网掩码），跨网段需网络管理员放行路由。
  5. 在对方主机执行 ping 本机IP 与 telnet 本机IP 11235 判断是网络不通还是仅端口被拦。
