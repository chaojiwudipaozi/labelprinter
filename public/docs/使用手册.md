# 标签打印工具站 · 使用手册（安装版）

> **适用对象**：通过安装包（`LabelPrint-Setup-1.2.1.exe`）安装到 Windows 电脑的用户
> **系统要求**：Windows 10 / 11（64 位）　**版本**：**V1.2.1**
> **本手册无需任何命令行操作**，全部在软件界面中完成。

---

## 一、安装与启动

### 1. 安装

1. 双击安装包 **`LabelPrint-Setup-1.2.1.exe`**；
2. 如出现「用户账户控制」提示，选择「是」；
3. 选择安装位置（默认即可，也可点「更改」装到 D 盘等）；
4. 一路「下一步」直到完成；
5. 安装完成后，桌面与开始菜单会出现 **「标签打印工具站」** 快捷方式。

> 安装包是**免联网**的，安装后无需再安装 Node.js、Excel 等任何环境。
> **升级到新版**：直接双击新版本安装包覆盖安装即可，已保存的标签模板与设置不会丢失（模板存于用户数据目录，卸载/覆盖安装都不删除）。

### 1.1 确认当前版本（是否已是最新）

安装/升级后请核对版本号，界面左上角标题旁会显示 **`V1.2.1`** 这样的版本徽标：

- 鼠标悬停徽标会显示：**安装包（主程序）版本**、**网页层（界面）版本**、是否为桌面安装版、数据目录、Node 版本；
- 也可以通过菜单 **「帮助 → 关于本工具」** 查看版本；
- **版本号只增不减**：软件不会让界面回退到旧版本（详见第十一章「增量更新」）；
- 若显示的版本**低于**你安装的安装包版本，说明打开的是旧程序：请完全退出程序（含右下角托盘/任务栏）后重新打开，或在界面按 `Ctrl+F5` 强制刷新。

### 2. 启动

双击桌面 **「标签打印工具站」** 图标即可。程序会：

1. 自动在本机启动内置服务（默认端口 11235，被占用时自动换端口）；
2. 自动打开软件主窗口；
3. **自动检测本机（这台电脑）安装的所有打印机**。

启动后建议等待 3~5 秒，等右上角打印机状态显示出来再开始操作。

### 3. 卸载

控制面板 →「程序和功能」→「标签打印工具站」→ 卸载。

> **重要**：卸载**不会删除**你的标签模板和数据（存放于 `C:\Users\<你的用户名>\AppData\Roaming\label-print-site\data`），
> 重新安装后模板依旧可用，无需重新设计。

## 二、五分钟快速上手

| 步骤 | 操作位置 | 做什么 |
|---|---|---|
| ① 打开示例 | 功能区「开始」→ **「示例模板」** | 载入一个现成的物料标签，先熟悉效果 |
| ② 准备数据 | Excel / WPS | **任意 Excel 都能用**：第一行写字段名，往下每行 = 一张标签的数据（也可先用「下载Excel模板」拿推荐格式） |

- 卡片显示：模板名、元素数、标签尺寸、绑定的打印机、保存时间；
- **单击卡片即载入**该模板（当前模板蓝色高亮）；

数据区采用**可折叠抽屉**样式，**默认收起**，只保留一条标题栏，把纵向空间让给标签纸区域：

| 位置 | 说明 |
|---|---|
| 标题栏（常驻） | `▲ 标签数据（Excel）` + **实时统计**（共 N 行 · 合计 M 份 · 预览第 K 行） |

## 四、设计你的标签

### 1. 设置标签纸尺寸

功能区「开始」→ 点击 **「标签纸 100 × 60 mm」** 按钮：

- **标准尺寸**：常用条码/热敏标签（100×150、100×100、100×80、100×70、100×60、90×60…50×30）、仓储物流面单（100×180、76×130、4×6 英寸、3×4 英寸）、线缆资产小标签、办公打印纸（A4/A5/B5/Letter/A6）共 **27 个**，点击即选中；
- **自定义尺寸**：手动输入宽、高；单位可选 **毫米（默认）/ 厘米 / 英寸**；
- **⇄ 纵向/横向互换**、**复位为 100×60**；
- 右侧**实时预览**：显示 mm 与 inch 双单位、方向与长宽比；
- 可输入范围 **10 ~ 500 mm**；若缩小后已有元素超出范围，会提示「N 个元素超出新范围」。

> 标签尺寸必须与实装标签纸一致，否则打印会缩放或走纸异常。

### 2. 插入元素

| 元素 | 说明 |
|---|---|
| 文本 | 最常用。可静态文字，也可绑定 Excel 字段 |
| 条形码 | 支持 CODE128、CODE39、EAN13、EAN8、UPC、ITF14、ITF、MSI、pharmacode、codabar |
| 二维码 | 纠错等级 L / M / Q / H |
| 矩形框 / 直线 | 做边框、分隔线（线宽可调） |
| **表格** | 可预选行×列，支持合并单元格 |
| **当前日期时间** | 自动显示当前时间，默认格式 `2026/9/21 09:05`（月份不补零） |

**两种插入方式**：
1. 点功能区「插入」页签里的组件按钮；
2. 直接在**画布空白处按住拖拽**，画出一个文本区域（自动按框高匹配字号）。

### 3. 选中与调整

| 操作 | 方式 |
|---|---|
| 选中 | 单击元素 |
| 移动 | 按住拖动；或用 **方向键**微调 1mm（按住 `Shift` 微调 0.2mm） |
| 改大小 | 拖动**八个手柄**（四角 + 上下左右边） |
| 精确设置 | 右侧属性面板输入位置与尺寸（mm） |
| 复制 / 层级 / 删除 | 功能区「元素」分组；`Delete` 键删除 |
| **上一步 / 下一步** | 功能区「编辑历史」分组的 **`↺ 上一步`** / **`↻ 下一步`**，或快捷键 `Ctrl+Z` / `Ctrl+Y`（`Ctrl+Shift+Z` 也可重做） |

> **上一步 / 下一步能退回什么？** 画布上的全部设计改动：插入、删除、复制、拖动、改大小、改文字/绑定/字体/对齐、表格的行列增删与合并拆分、标签纸尺寸、导入数据、载入模板等；**最多回退 60 步**，连拖动这类连续操作会自动合并成一步（不会一次只退 1 像素）。
> 撤销后如果又做了新的改动，后面的「下一步」会被清空（与常见软件一致）。

### 4. 双击编辑与绑定字段

**双击**任意元素弹出快捷编辑器：

- **静态文字**：直接输入固定内容；
- **响应前缀**：如填 `物料编码：`，打印时显示 `物料编码：W0000123456`；
- **绑定 Excel 字段**：下方列出导入后的全部列名，**点一下即绑定**（未导入数据、或该行这一列本身为空时，屏幕上显示 `{列名}` 占位便于辨认，**打印时会自动留空**，不会把 `{列名}` 打出来）；
- **内容来源**：可选「静态文字 / Excel字段」或「当前日期时间」，选日期时间后可选 8 种格式；
- 字体、字号、加粗、水平/垂直对齐；
- 「清除绑定」「删除元素」。

### 5. 字体与字号

- 字体：宋体 / 黑体 / 微软雅黑 / 楷体 / 仿宋 / 等线 / Arial / Times New Roman / Courier New 共 **9 种**；
- 字号：**4~72pt**（支持 0.5 步进），也可用 `A+` / `A-` 快速调整；
- 规则：**选中元素 → 只改该元素；未选中 → 一次性应用到全部文字与条码元素**；
- **自适应字号（默认开启）**：文字（含条形码下方的可读文字）**始终一行显示**，内容超出元素宽度时**自动缩小字号**刚好放下（最小 3pt），不会被裁掉或挤成两行。
  - 可在属性面板或双击后的快捷编辑器里勾选/取消（取消后按设定字号**换行**显示）；
  - 表格单元格、文本框、条形码都支持；**合并单元格按合并后的整块宽度**计算，所以合并后字号会更大；
  - 把元素拉宽/缩小，字号会跟着自动变化；屏幕显示、浏览器打印、直连打印三处结果一致。

### 6. 表格

插入表格（插入页签 →「表格…」）：可**预选行数(1~30)×列数(1~20)**、表格宽高与线宽，带网格预览与常用规格快捷键。

插入后**自动进入编辑模式**（画布下方出现浮动工具条），此时可以：

| 操作 | 方法 |
|---|---|
| 框选单元格 | 在单元格上**按住拖拽**，出现蓝色选区 |
| 合并 | 框选多个单元格后点浮动条 **「合并单元格」**；**合并后内容默认上下左右居中** |
| 拆分 | 点 **「拆分」** |
| 调整行高/列宽 | 拖动单元格之间的**蓝色分隔线**：分隔线**精确跟随鼠标**，与该行/列的相邻行列此消彼长（表格总尺寸不变，单列最小 2mm、单行最小 1mm）。若要改变表格整体大小，用属性面板的「宽/高」或画布上的八个手柄 |
| 增删行列 | 浮动条 `＋行` `＋列` `－行` `－列`（增删后各单元格的内容/绑定会**随行随列一起移动**，不会错位） |
| 编辑单元格内容 | **双击单元格** → 可输入文字、绑定 Excel 字段、调字体与水平/垂直对齐 |
| **自适应字号（防溢出）** | 单元格属性里的 **「自适应字号」默认勾选**：内容始终保持**一行**；当字数多到一行放不下时，**自动缩小字号**刚好放进该单元格（最小 3pt）。取消勾选则按原字号**换行**显示 |
| 退出编辑 | 按 `Esc`、点浮动条 **「✓ 完成」**、或属性面板「✓ 完成表格编辑」 |

> **绑定与字体是「按单元格」生效的**：每个单元格各自绑定一个 Excel 字段，互不影响；双击哪个单元格，弹窗标题就会显示「编辑单元格（第 N 行 / 第 M 列）」，蓝色高亮的单元格就是当前正在编辑的单元格（点选其他单元格会自动切换编辑目标）。
> **字数太多放不下一行怎么办？** 默认已开启「自适应字号」：文字不会被截断也不会换行，而是自动变小到刚好放下（拖窄某一列时字会跟着变小，拖宽后会恢复到设定字号）。若希望保持原字号并换行显示，取消该单元格的「自适应字号」勾选即可。合并单元格按**合并后的整块宽度**计算，所以合并后字号会更大。
> 双击表格边框（非单元格）会提示「表格整体不能绑定字段」，此时请双击具体单元格。
> 打印时表格一律按**毫米**输出，与画布缩放（50%~200%）无关，不会出现打印放大/缩小的问题。

> **提示**：编辑模式**不会因为点击其他地方而退出**，你可以随时点回来继续操作；如果表格退出了编辑状态，选中表格后属性面板里点 **「✎ 编辑表格」** 即可重新进入。

### 7. 保存模板

功能区「开始」→ **「保存模板」** → 输入模板名 → 确定。

- 成功后右上角弹出绿色提示，标题行徽标变为 `✔ 已保存：模板名`；
- 模板随即出现在**左侧列表**，点击即可再次载入。

## 五、准备 Excel 数据

> **一句话规则：第一行是字段名，往下每一行是一张标签的数据。**
> 任意 Excel / CSV 都能直接导入，**不必非用标准模板**。

### 1. 导入任意 Excel 文件（日常用法）

点击「📥 导入Excel」选择你的表格即可，系统会自动完成：

| 自动处理 | 说明 |
|---|---|
| **识别字段名** | 默认把**第一行（第一行有内容的行）的每一列当作字段名**，往下每行作为一组取值（一行 = 一张标签） |
| 跳过标题/说明行 | 表格前面若有标题行、说明行、空行，会自动跳过，并在「导入结果」里注明「表头取自第 N 行」 |
| **多个工作表全部识别** | 一个工作簿里有多个工作表时，**默认全部导入并合并**：先挑出最像数据表的那张作为「主表」，其余工作表**按列名对齐**合并（多出的新列自动追加），例如「一月」3 行 + 「二月」2 行 → 共 5 行 |
| 清理列名 | 去掉首尾与中文列名内的多余空格（「物料 编码」→「物料编码」）；重复列名自动加序号（如 `物料编码(2)`）；无列名但有数据的列自动命名「列3」 |
| 忽略空行/空列 | 整行为空的行忽略；无列名且整列全空的列忽略 |
| 合并单元格 | 合并标题只取左上角内容，其余列自动命名 |
| 日期与数字 | 日期统一成 `2026-08-24`；百分比、千分位、文本前导零按 Excel 显示效果保留 |
| 文件编码 | CSV 自动识别 UTF-8 / GB18030(GBK) / Big5，Excel 另存的中文 CSV 不会乱码 |
| 合计行 | 检测到「合计/小计/汇总」行会提示（不会自动删除，如需排除请在原表中删除该行） |

导入后底部会出现**「导入结果」面板**，显示有效行数 × 列数与每张工作表的处理结果，可调整项：

- **导入全部 N 个工作表**（默认勾选，多工作表时出现）：所有工作表的数据合并导入；此时「工作表 / 表头行」置灰，因为**每张表各自自动识别表头行**；
- **取消勾选**后进入单表模式：**工作表**下拉可指定某一张表（切换后自动重新解析），**表头行**默认自动（通常就是第 1 行），识别不对时填入真正字段名所在行号，再点 **「↻ 重新解析」**；
- 面板中会逐表列出结果，例如：`工作表：一月 3 行（主表） | 二月 2 行　|　填写说明 已跳过（列名与主表无相同项）`。

> **哪些工作表会被跳过？** ①没有任何数据行的表；②列名与主表**完全没有相同列**的表（通常是「填写说明」这类文字表）——跳过原因会写在面板里，需要导入它时取消勾选后单独选择该表即可。
> 合并时**列名相同即视为同一列**（忽略大小写与空格，如「物料 编码」=「物料编码」）；某张表没有的列，其行对应位置留空。

> 字段名就是**绑定用的名字**：双击标签元素后点击字段名即可绑定，字段名叫什么就按什么绑定。
> 若某列为空且无列名会被忽略；若你的表格确实需要该列，请在原表给它填个列名。

### 2. 下载标准模板（可选）

底部「标签数据」→ **「下载Excel模板」**，得到 `标签打印数据模板.xlsx`，含两个工作表：

- **标签数据**：17 列标准字段 + 2 行示例；
- **填写说明**：填写规范（务必按说明填写）。

### 3. 标准字段（17 列，模板用）

| 序号 | 列名 | 说明 |
|---|---|---|
| 1 | 物料编码 | 物料唯一编号 |
| 2 | 物料名称 | 物料中文名 |
| 3 | 规格 | 如 787×1092mm |
| 4 | 型号 | 供应商标注型号 |
| 5 | 数量 | 本次数量 |
| 6 | 单位 | 张 / 卷 / 个 |
| 7 | 批号 | 生产批号 |
| 8 | 序列号 | 单件序列号 |
| 9 | 供应商编码 | 供应商编号 |
| 10 | 供应商名称 | 供应商全称 |
| 11 | 生产日期 | 建议 `2026-08-24` 文本格式 |
| 12 | 有效期至 | 同上 |
| 13 | 采购单号 | 关联采购单 |
| 14 | 任务单号 | 关联生产任务 |
| 15 | 二维码内容 | **可留空**，导入时自动按「物料编码;批号;生产日期」生成 |
| 16 | 条码内容 | **可留空**，导入时自动取「物料编码」 |
| 17 | **打印数量** | **该行需要连续打印的份数**；留空或填 1 表示只打 1 份；填 0 表示该行不打印 |

### 4. 填写规范

1. **不要修改第 1 行的列名与顺序**，否则导入后无法自动绑定字段；
2. 从第 2 行开始，**一行数据 = 一张标签**；整行为空的行会被自动忽略；
3. 日期建议用 `YYYY-MM-DD` 文本；不要使用公式与合并单元格；
4. 需要额外字段时，可在标准列**右侧自行追加列**，导入后同样能绑定。

### 5. 导入结果与校验报告

底部 → **「导入Excel」** → 选择文件。导入后会出现**校验报告条**：

- 有效数据行数 × 列数、忽略的空行数；
- ⚠ 缺少标准列（红色标签，相关元素将显示占位符）；
- ＋ 附加列（可作为绑定字段）；
- ⚙ 自动生成/填充的列（二维码内容、条码内容）；
- 若有汇总信息，还会显示合计打印份数。

### 6. 「打印数量」列（重要）

导入后，底部表格**最后一列就是「打印数量」**：

- 直接在该单元格输入数字 → 回车（或点别处）即生效；
- **填 0** 表示该行不打印；填 3 表示该行**连续打印 3 份**；
- 表头右侧实时统计：`共 12 行 · 合计 26 份（4 行设置了多份）`；
- 批量改份数：数据区 **「统一份数」** 输入数字 → 点「应用」，全部行设为同一份数。

> 打印数量会随草稿自动记忆，刷新页面不丢失；若 Excel 里已填「打印数量」列，导入时自动读取。

### 7. 清空 / 更换数据

数据区 **「清空数据」** → 确认（不影响已保存的标签模板）。

## 六、打印

### 1. 选择打印机

顶部 `🖨 打印机` 下拉中选择目标打印机（下拉里带 `★` 的是系统默认打印机）。

**右侧状态徽标含义**：

| 状态 | 颜色 | 含义 | 处理建议 |
|---|---|---|---|
| 空闲 | 绿 | 就绪，可立即打印 | — |
| 打印中 | 蓝 | 正在出纸或队列有任务 | 等待完成 |
| 脱机 | 灰 | 设备未连接/未开机 | 检查电源、USB/网线；Windows「设备和打印机」中取消「脱机使用打印机」 |
| 已暂停 | 黄 | 队列被暂停 | 在打印队列中恢复 |
| 异常 | 红 | 卡纸、缺纸、碳粉不足、需用户干预等 | 鼠标悬停状态徽标可看具体原因 |
| 未知 | 灰 | 驱动未报告状态 | 一般可正常打印 |

点 **「详情」** 可查看全部打印机明细（品牌、驱动、端口、状态、队列长度），并可直接「选为打印目标」。

### 2. 打印方式

| 方式 | 位置 | 特点 |
|---|---|---|
| **批量打印（推荐）** | 功能区「打印」页签 或 数据区 | **直连打印机，不弹浏览器打印框**；按每行「打印数量」连续出纸 |
| 打印当前行 | 功能区「打印」页签 或 数据区 / 数据表双击「打印」 | 只打印底部表格中选中的那一行（按其份数） |
| 浏览器预览打印 | 功能区「打印」页签 | 备用方式，会弹出浏览器打印对话框，可自行预览/选择纸张 |

**批量打印流程**：点「批量打印」→ 确认框显示「共 N 行、合计 M 份、目标打印机」→ 点「开始打印」→ 标签逐张送入打印机队列。

> 若标签中的「当前日期时间」元素，会取**打印那一刻**的时间。
>
> **空值怎么打？** 绑定的字段在某行数据里为空（或该列不存在）时，屏幕上仍显示 `{列名}` 占位（便于设计时确认绑定关系），但**打印时该位置留空**——文字、前缀、条形码、二维码、表格单元格都一样处理，不会把 `{列名}` 印到标签上。

### 3. 打印前检查清单

- [ ] 目标打印机已选中，且状态不是「脱机/异常」；
- [ ] 标签纸尺寸与实装标签纸一致；
- [ ] 各元素绑定的字段在**校验报告**中没有报「缺少标准列」；
- [ ] 「打印数量」列已核对（合计份数符合预期）；
- [ ] 打印机纸张规格已在驱动中匹配（首次使用建议先用「浏览器预览打印」试一张）。

## 八、局域网共享（可选）

其他电脑无需安装软件，用浏览器即可使用本机的这套工具：

1. 在本机软件中点击标题行的 **「● 服务端已连接」** → 弹出「局域网访问地址」，里面列出本机与局域网地址，可一键复制；
2. 把局域网地址（形如 `http://192.168.1.23:11235`）发给同事，用浏览器打开即可；

4. 若同事打不开：多为 **Windows 防火墙**拦截入站连接。以**管理员**身份运行一次安装目录下的

5. 若需要「打印到某台电脑自己的打印机」，请在那台电脑上也安装本软件（或在网页端右上「打印服务」里填写那台电脑的打印服务地址）。

> **注意**：软件安装到哪台电脑，就使用**那台电脑**的打印机。要使用另一台电脑的打印机，请在那台电脑上安装本软件，并在网页端「打印服务」中切换。

## 九、常见问题（FAQ）

**Q1：打印机列表里没有我要的打印机怎么办？**
本软件只列出 **Windows 已安装的打印机**。若「设置 → 蓝牙和其他设备 → 打印机和扫描仪」里也没有，说明系统层还没装好：
1. 安装厂商驱动（斑马打印机装 **ZDesigner** 驱动，其他品牌装官方驱动）；
2. 装好后用安装目录 `scripts\add-printer.ps1`（需管理员）或系统「添加打印机」把它加进 Windows；
3. 回到软件点打印机旁的 `↻` 刷新。
另外可点打印机「详情」→ **「诊断：为什么找不到我的打印机？」**，软件会给出针对本机的结论（例如「发现已创建但没有任何打印机使用的 TCP/IP 端口」「已安装斑马驱动但没有对应打印机」）与可复制的处理命令。

**Q2：点了打印但打印机不动？**
1. 看状态徽标是否为「脱机」→ 检查设备电源与连接，取消 Windows 的「脱机使用打印机」；
2. 是否「异常」→ 悬停徽标看原因（缺纸/卡纸/碳粉）；
3. 是否选错了打印机；
4. 到 Windows 的打印队列里看任务是否卡住。

**Q3：为什么「批量打印」不弹框，而「浏览器预览打印」会弹？**
浏览器出于安全策略，网页打印**必然**弹系统打印对话框，无法绕过。「批量打印」走的是**软件直连打印机**的方式，因此没有弹框——这也是推荐方式。

**Q3-1：导入后字段名不对（出现「列3」「物料编码(2)」），或者只导入了标题？**
字段名取自**表头行**。请在底部「导入结果」面板里确认「表头取自第 N 行」是否正确：
- 若不对，把「表头行」改填真正的字段名所在行号 → 点「↻ 重新解析」；
- 出现「列N」说明该列在表头行里没有列名（可回原表补上列名，或在标签里改用其它字段）；
- 出现「物料编码(2)」说明原表有两列同名，系统自动加了序号以免互相覆盖；
- 有多张工作表时，用「工作表」下拉切换到存放数据的表。

**Q3-2：我的 Excel 里有多个工作表 / 前面有标题和说明行，会影响导入吗？**
不会。系统会自动挑选数据工作表，并自动跳过标题、说明与空行，只把最后确定的「表头行」当作字段名行；两者都能在「导入结果」面板里手动调整。

**Q3-3：中文 CSV（Excel 另存为 CSV）导入后乱码？**
新版已支持自动识别 UTF-8 / GB18030(GBK) / Big5 编码，不会乱码。若仍有异常，请在「导入结果」里确认是否为正确的工作表，或改用 .xlsx 保存后导入。

**Q3-4：Excel 里的日期导入后变成数字（如 46258）？**
新版已修复：日期统一输出为 `2026-08-24`（带时间的为 `2026-08-24 09:05`）；百分比、千分位、文本前导零仍按 Excel 的显示效果保留。

**Q4：导入后某些字段显示 `{字段名}`（花括号）？**
说明该元素绑定的列在当前 Excel 中不存在（或该行为空）。看底部**校验报告**里缺少的标准列，或用模板重新导出填写。

**Q5：打印出来的尺寸不对 / 每张标签跑偏？**
标签纸尺寸必须与实装纸完全一致（功能区「标签纸」里设置）；同时确认打印机驱动中的纸张规格与之一致。首次调试建议先「浏览器预览打印」试一张。

**Q6：表格点别处后不能编辑了？**
新版已修复：编辑模式不会因点击别处而退出。若确实退出了，**选中表格 → 属性面板点「✎ 编辑表格」**，或直接**双击表格**重新进入；退出按 `Esc` 或「✓ 完成」。

**Q6-1：拖动表格的行列线时会跳、不跟手？**
新版已修复（分隔线精确跟随鼠标，相邻行/列此消彼长，最小列宽 2mm / 行高 1mm）。

**Q3-5：表格单元格里的字太多，显示不全（被截断或挤成两行）？**
已默认开启**「自适应字号」**：内容始终一行显示，字数超出时自动缩小字号刚好放下。可在**单元格属性**或**双击单元格的快捷编辑窗口**里勾选/取消：
- 勾选（默认）：一行显示，字多自动变小（最小 3pt）；
- 取消：按设定字号显示，超出部分**换行**（行高不够时会被裁掉）。

拖窄某一列时字号会跟着变小，拖宽后会回到设定字号；合并单元格按合并后的整块宽度计算。

**Q4-1：底部的 Excel 数据区把标签挡住了 / 想让它别占地方？**
数据区已改为**上拉式抽屉**：默认收起，只留一条标题栏（显示行数与份数统计）。**点击标题栏即上拉展开，再点一次向下收起**，展开/收起状态会被记住。收起状态下仍可直接点标题栏上的「📥 导入Excel」「🖨 批量打印」。若标签仍显得拥挤，可把「缩放」调到 200% 或收起左侧模板列表。

**Q5-1：标签看起来太小/太大，怎么调整显示大小？**
用功能区「开始」→「缩放」下拉：50% / 75% / 100% / **150%（默认）** / 200%。150% 是**等比放大**——标签的长宽比保持不变，文字、条码、二维码、表格线宽都按同一比例放大，因此屏幕上看到的就是打印出来的样子；**缩放只影响显示，不影响打印尺寸**。你手动选择过的比例会被记住，下次打开仍按你的选择显示。

**Q6-2：表格单元格绑定字段后，文字跑到别的格子里 / 再打开显示「未绑定」？**
新版已修复，原因为：多个表格共用了一份单元格数据、以及属性面板会重置编辑目标。现在每个单元格**一对一独立绑定**；若仍遇到，请确认是**双击具体单元格**再点字段名（表格整体不能绑定字段），并在打印前查看属性面板中的绑定列。

**Q7：文字居中不生效？**
新版已修复（屏幕、浏览器打印、直连打印三处对齐一致）。若仍异常，请重新选择对齐方式（属性面板「对齐」或双击后「水平对齐」）。

**Q8：重装软件后模板会丢吗？数据在哪？**
不会丢。模板存于 `%AppData%\label-print-site\data\labels`，卸载不删除；换电脑时复制该文件夹即可。

**Q9：杀毒软件/防火墙提示怎么办？**
本软件需访问本机打印服务（打印后台处理程序）与读写自己的数据目录，属正常行为，选择「允许」即可。局域网访问需要放行入站端口（见第八节）。

**Q10：程序双击没反应 / 提示端口被占用？**
1. 看任务栏是否已有窗口（可能最小化）；
2. 软件对端口被占用会自动换端口，一般不会失败；若仍失败，请重启电脑后重试；
3. 检查是否被安全软件拦截。

**Q11：换了一台电脑，打印机不见了？**
打印机识别依赖运行软件的这台电脑，换电脑后需在该电脑上安装对应打印机驱动并添加打印机。

**Q12：页面上的「统一份数」和表格里的「打印数量」是什么关系？**
「统一份数」是**批量设置工具**，点「应用」后会把所有行的打印数量改成同一个值；平时逐行修改表格里的数字即可。

**Q13：装了新版安装包，界面版本号却显示旧版本（例如装的是 V1.2.1，界面显示 V1.0.4）？**
这是**旧版热更新残留**导致的（以前热更新下载的网页文件比安装包旧，把新文件挡住了）。新版已从根上解决：
- 启动时会**自动清理**过期的热更新文件，界面立即回到安装包自带版本；
- 版本号**只增不减**：热更新只有在"比你安装的安装包更新"时才生效；
- 「版本日志」页签里会分别显示 **安装包版本** 与 **网页层版本**，两者正常应一致（热更新后网页层更高，徽标带 `⁺`）。

若仍显示旧号：先 `Ctrl+F5` 强制刷新；再不行就在「版本日志」页签点 **「清除过期文件」**（或「↩ 回滚到安装版本」），然后刷新界面。

**Q14：检查更新提示"更新源网页层版本较低"？**
说明你填的**更新源那台电脑**上的软件版本比你本机低。软件会**拒绝降级**（不会把界面刷回旧版），因此提示"无需更新"。请把更新源换成**装有最新版**的那台电脑，或先把那台电脑升级。

**Q15：我的 Excel 里有好几个工作表，能一起导入吗？**
能。**默认就会把所有工作表一起导入**：软件挑出最像数据表的那张当主表，其余表**按列名对齐合并**（某表独有的列会自动追加成一列）。导入结果面板里会逐表列出「几行 / 已跳过（原因）」。
「填写说明」这类纯文字表会因**列名与主表完全没有相同的列**被跳过（不影响导入）；若确实要单独导入它，取消勾选「导入全部 N 个工作表」，从「工作表」下拉里选它即可。

**Q16：改错了、想退回上一步？**
点功能区「开始」→「编辑历史」里的 **`↺ 上一步`**，或按 `Ctrl+Z`；退回多了用 **`↻ 下一步`** / `Ctrl+Y` 前进。插入、删除、拖动、改字/绑定/字体/对齐、表格增删合并、标签尺寸、导入数据、载入模板都能回退，最多 60 步（连续拖动会合并成一步）。

**Q18：打印出来有 `{字段名}` 这样的文字？**
V1.2.1 起已改进：绑定的字段为**空值**时，屏幕上仍显示 `{字段名}` 占位（方便设计时辨认），但**打印时该元素留空**——包括它的前缀（如「批号：」）、条形码/二维码占位框、表格单元格，都不会打印出来。
若打印结果里仍然出现 `{字段名}`，说明界面没有更新到 V1.2.1：请 `Ctrl+F5` 强制刷新，或在「版本日志」页签从 exe 内更新到最新版。

**Q17：表格里的文字居中不生效 / 打出来不居中？**
V1.2.0 已修复：单元格的水平对齐此前在屏幕上和打印预览里会被忽略（垂直居中正常）。现在**屏幕显示、浏览器打印预览、直连打印**三处的水平/垂直对齐完全一致；合并单元格默认上下左右居中。若样式仍不对，请 `Ctrl+F5` 强制刷新界面（或按第十一章从 exe 内更新到最新版）。

## 十一、版本日志与增量更新

### 1. 版本日志（每个版本更新了什么）

功能区最右侧的 **「版本日志」页签**：

- 点 **「📄 版本日志」** 打开完整日志（Markdown 排版，可打印）：按版本号倒序列出每个版本的**新增 / 优化 / 修复**内容；
- 页签内还显示**当前版本**与**更新源**状态；
- 同样的内容也随安装包附带：`<安装目录>\resources\docs\CHANGELOG.md`。

### 2. 增量更新（不用重装安装包）

软件把界面层拆成了可热更新的部分，升级时**只下载有变化的文件**：

| 层 | 包含 | 更新方式 |
|---|---|---|
| **网页界面层** | 界面、样式、前端逻辑、使用手册与版本日志（`public/**`、`docs/**`） | **增量更新**：软件内点「🔄 检查更新」→「⬇ 下载并应用更新」→「立即刷新界面」 |
| **主程序层** | Electron 主进程、内置服务、PowerShell 脚本、依赖库 | **完整安装包**：装新版 `LabelPrint-Setup-*.exe`（模板与设置不会丢失） |

**用法**：

1. 在局域网内**任意一台装有最新版软件**的电脑上保持软件运行（它就是"更新服务端"）；
2. 在需要升级的电脑上打开软件 →「版本日志」页签 → **「⚙ 更新源」** → 填写那台电脑的地址（例如 `http://192.168.1.23:11235`）；
3. 点 **「🔄 检查更新」**：显示是否已是最新；若有新版会显示 **变化文件数**，可先点「查看更新内容」看新版日志；
4. 点 **「⬇ 下载并应用更新」**：文件逐个校验 **SHA-256** 后写入本机覆盖目录（`%APPDATA%\label-print-site\data\web`），**不修改安装目录里的任何文件**；
5. 点 **「🔄 立即刷新界面」** 生效（无需重启、无需重装）。

**安全与回滚**：

- 每个文件都会校验 SHA-256，校验不一致会被拒绝；非法路径（`../`）也会被拒绝；
- 随时可点 **「↩ 回滚到安装版本」**（或面板里的 **「清除过期文件」**）清除已下载的更新，回到安装包自带版本（数据与模板不受影响）；
- 若更新源的主程序版本更高但网页层文件一致，软件会提示"该更新涉及主程序，请安装完整安装包"，避免更新后版本错配。

**版本只增不减（重要）**：

| 规则 | 说明 |
|---|---|
| 热更新 = "补丁超前" | 热更新下载的网页层，只有在**版本号 ≥ 安装包版本**时才生效 |
| 装了新版安装包后，旧热更新自动失效 | 例如先热更新到 V1.1.1，之后又装了 V1.1.2 安装包 —— 那套 V1.1.1 的网页文件会被**自动忽略并清理**，直接使用安装包里的新文件（不会出现"装了新版界面还是旧的"） |
| 不会把界面刷回旧版 | 若更新源版本**比你本机低**，面板会提示"更新源网页层版本较低"，并且**不提供**下载按钮 |
| 面板会显示两个版本 | 「安装包版本」与「网页层版本」分开显示；正常情况下两者一致，热更新后网页层会更高（徽标带 `⁺`） |

> 更新源必须是**装有最新版**的那台电脑；指向旧版本电脑时不会造成降级，但也没有可用的新内容。
> 也可以通过菜单「帮助 → 检查更新」一键跳到该面板。

### 3. 给其他电脑装最新版（右上角「⬇ 下载安装包」）

标题行右上角的 **`⬇ 下载安装包`** 按钮，用于**一键下载最新版安装包**（`.exe`），适合这两种场景：

- 新电脑要装这个软件：把它指向装了软件的那台电脑的网址，点按钮下载 → 双击安装；
- 有些更新必须装完整安装包（面板提示"请安装完整安装包"）：直接点按钮下载，不用再找 U 盘/共享目录。

**怎么让按钮有内容？** 服务器（提供网页的那台电脑）上要放一个安装包文件：

| 电脑类型 | 放置位置 |
|---|---|
| 桌面版（exe 安装的） | `<数据目录>\installer\`（数据目录可在版本徽标悬停提示里看到，通常是 `C:\Users\你的用户名\AppData\Roaming\label-print-site\data`） |
| 网页版 / 免安装版（源码运行） | 程序目录下的 `dist\`（自动包含刚打包出的安装包），或任意一份 `LabelPrint-Setup-*.exe` 放在程序目录旁 |

放好后**刷新页面**，按钮悬停会显示「下载安装包 LabelPrint-Setup-x.y.z.exe（版本 + 大小）」。

- 目录里放了多个版本时，**自动取版本号最高**的那个；旧的可以留着自己清理；
- 只识别 `LabelPrint-Setup-*.exe` 这个命名（其它文件不会被下载，安全）；
- 局域网内任何一台电脑打开网页都能下载同一个安装包；按钮旁灰显表示**当前服务器上还没放安装包**，点它会给出去哪放的提示；
- 「版本日志」页签里若提示"更新源的主程序版本更高，需安装完整安装包"，可直接用旁边的 **`⬇ 从更新源下载安装包`** 从更新源那台电脑下载。
